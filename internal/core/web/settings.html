Spoken alert

The alert needs the dashboard script.

This browser speaks the alert, for example "koinon: a decision waits for you", with the repository of each item, while a dashboard page is open. The switch covers every repository of this Koinon instance. The browser keeps it for this dashboard address (scheme, host and port), so 127.0.0.1, [::1], an SSH tunnel's port and a new port each have their own switch. A browser speaks only after a click on the page: after a reload, the alert waits for your next click.

Change the session timing

The three values are checked together: the renewal interval must be at most half the lifetime. A change applies at once, without a restart, and the audit log records it.

Change a family's context handoff

A change applies to the family's sessions at once and enables none of them. The audit log records it.
